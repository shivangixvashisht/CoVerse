# Roadmap

Each milestone is reviewed before the next begins.

1. **Scaffold (this milestone)** — monorepo, dashboard UI with demo data, read-only MetaMask connection, minimal
   registry contract with tests.
2. **Split creation flow** — form to create a project and split; register it on a local Hardhat chain; read projects
   back from the contract.
3. **Contributor approvals** — collaborators sign off on a split before it's final; amendment rules.
4. **Revenue distribution** — pull-based payment splitter for ETH/ERC-20 with extensive tests and a threat model.
5. **Testnet deployment** — deploy to a public testnet; never mainnet without an external audit.
